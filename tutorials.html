💻 Windows 平台客户端使用教程指南

方案一：Clash Verge Rev（强烈推荐电脑用户首选）

老版 Clash for Windows (CFW) 停止维护后，Clash Verge Rev 已成为目前 Windows 上最流行、更新最频繁的现代客户端，界面极简优雅且原生支持 TUN 虚拟网卡模式。

第一步：下载与安装

前往官方 Releases 页面，根据电脑配置下载对应安装包：

  • 64位 Windows 常见推荐：Clash.Verge_x.x.x_x64-setup.exe
  • 安装过程中若弹出 Windows Defender 拦截，点击「更多信息」->「仍要运行」即可。
前往 GitHub Releases 官方下载 ↗

第二步：获取并导入节点订阅

1. 前往您所使用的 15家专线机场 个人中心，或前往本站 免费节点专区，点击「复制 Clash 订阅链接」；

2. 打开 Clash Verge Rev 客户端，点击左侧菜单栏的 「订阅 (Profiles)」；

3. 在顶部输入框粘贴刚才复制的订阅 URL 地址，点击右侧的 「导入 (Import)」 按钮；

4. 导入成功后，鼠标右键点击该配置卡片，选择 「使用 (Use)」（卡片右上角亮起绿色对勾即为生效）。

第三步：开启系统代理与选择分流节点

1. 点击左侧 「代理 (Proxies)」，在「规则 (Rule)」模式下点击测试延迟，展开节点列表，选择延迟低且绿色的节点（如香港、日本、美国 IPLC 节点）；

2. 点击左侧 「设置 (Settings)」，找到 「系统代理 (System Proxy)」 开关并打开，即可在 Chrome/Edge 浏览器中顺畅访问海外网络；

3. TUN 模式（可选进阶）：若玩外服游戏、使用 Telegram 桌面版或终端命令行代理，可开启「TUN 模式」（首次开启会提示安装虚拟网卡驱动，点击确认即可）。

方案二：v2rayN（适合极客、单节点导入与高级调试）

第一步：下载核心包：下载 v2rayN-with-dependencies.zip（自带完整运行时依赖），解压后运行 v2rayN.exe。

第二步：添加订阅与测速：

  • 点击顶部菜单 「订阅分组」 -> 「订阅分组设置」 -> 「添加」；
  • 在备注填写机场名称，在「可选地址 (URL)」填入订阅链接，点击保存；
  • 点击顶部菜单 「订阅分组」 -> 「更新全部订阅 (不通过代理)」，即可加载出全部节点；
  • 选中所有节点按快捷键 Ctrl + R 进行「测试真实延迟」，选择数值在 100ms~300ms 左右的可用节点，按回车激活。

第三步：开启代理：在屏幕右下角托盘图标右键 -> 勾选「自动配置系统代理」，路由规则推荐选择「绕过大陆 (Whitelist)」。

🍎 macOS 苹果电脑平台配置教程

macOS 上同样首选 Clash Verge Rev for Mac，兼容 Intel 芯片与 Apple Silicon (M1/M2/M3/M4) 系列。

安装与系统授权步骤：

  1. 根据 Mac 芯片下载对应 .dmg 安装包（M系列芯片请下载 _aarch64.dmg，Intel 芯片下载 _x64.dmg）；
  2. 打开 dmg 文件，将「Clash Verge」图标拖动到「Applications (应用程序)」文件夹；
  3. 首次启动若提示无法打开，请前往 Mac 「系统设置」->「隐私与安全性」，下滑找到该应用点击「仍要打开」；
  4. 导入订阅后，在左侧打开「系统代理」开关即可顺畅出海。若提示需要网络权限，输入当前 Mac 的管理员开机密码授予即可。

📱 iOS (iPhone / iPad) 教程：Shadowrocket (小火箭)

在苹果 iOS 生态中，Shadowrocket（俗称小火箭）是公认体验最好、上手最快的代理客户端。

特别注意：中国大陆区 App Store 已下架所有翻墙代理软件。请勿在系统「设置」中登录外区 iCloud（防止锁机），必须且只能在 「App Store 应用商店」 退出原有账号，登录外区 Apple ID 进行下载。可查阅本站 外区 Apple ID 免费共享与注册教程 ↗。

详细配置步骤：

步骤 1：一键快速导入订阅

  • 方式 A（一键唤醒）：在 Safari 浏览器中登录您的 机场后台，找到「一键导入小火箭」按钮点击，会自动拉起 App 并保存节点；
  • 方式 B（手动扫码/粘贴）：打开 Shadowrocket 首页，点击右上角 「+」 号，在「类型」下拉菜单中选择 Subscribe (订阅)；在「URL」栏中粘贴您的订阅地址，备注填写名称，点击右上角「完成」即可同步所有节点。

步骤 2：选择节点与测速

在首页找到导入好的订阅列表，点击「节点连通性测试」，测出的毫秒数越小代表响应越快。点击选中你想要使用的节点（节点前方出现黄色/绿色圆点即为选中）。

步骤 3：全局路由与启动 VPN

将首页下方的「全局路由」设置为 「配置 (Config)」（该模式可智能分流：访问百度/微信直连走本地网络，访问 YouTube/Google 走代理节点）；

打开小火箭顶部最上方的第一行开关，首次连接会弹出 iOS 系统提示「Shadowrocket 想要添加 VPN 配置」，点击「允许 (Allow)」并输入锁屏密码即完成连接。

🤖 Android (安卓手机/平板/电视盒子) 教程

安卓端推荐安装 Clash Meta for Android (CMFA) 或 v2rayNG。

Clash Meta for Android 简明操作：

  1. 安装并打开 App，点击底部的 「配置 (Profiles)」 选项；
  2. 点击右上角的 「+」 号 -> 选择 「URL 导入 (从 URL 获取)」；
  3. 在「名称」中随意输入，在「URL」栏粘贴机场或本站免费节点的订阅链接，点击右上角「保存」下载配置；
  4. 返回主页面，点击中部的「配置」选中刚才下载好的卡片；
  5. 点击主屏幕中部的总开关（启动），首次运行允许系统建立 VPN 连接权限即可；
  6. 在「代理」页面中可以按延迟排序选择最优质的专线节点。

🐧 软路由、家庭路由器与 Linux 平台使用指引

如果你使用的是小米、红米、华硕、中兴或自建 OpenWrt 软路由，可以在路由器底层直接运行代理内核，实现全屋手机、电视、PS5/Switch 游戏机免客户端无感科学上网。

ShellCrash 路由器一键脚本安装步骤：

1. 路由器开启 SSH 权限，使用终端或 PuTTY 工具通过 SSH 连接到路由器控制台；

2. 执行以下开源一键安装脚本命令：

ShellCrash 官方一键安装命令 ● 开源脚本
export url='https://fastly.jsdelivr.net/gh/juewuy/ShellCrash@master' && sh -c "$(curl -kfsSl $url/install.sh)" && source /etc/profile &> /dev/null

3. 脚本会自动引导你选择内核类型，推荐选择 Meta 内核；

4. 按照提示输入订阅链接地址，开启开机自启与透明代理重定向；

5. 访问 http://路由器IP:9999/ui 即可打开可视化仪表盘（Yacd / Metacubexd）实时切换节点与查看流量。

🛠️ 新手常见报错与故障排错速查手册 (FAQ)

Q1：为什么在客户端点击测速全部超时（Timeout）或显示 100% 丢包？

排查要点：
1. 电脑/手机系统时间误差：这是 90% 用户测速失败的原因。TLS 加密连接要求本地设备时间与互联网国际标准时间误差不能超过 90 秒。请前往系统设置将时间调整为「自动同步网络时间」。
2. 订阅链接失效或欠费：检查所用机场套餐是否已用尽流量，或前往本站 跑路预警专区 确认是否遭遇线路封禁。

Q2：节点测试有几十毫秒延迟，但浏览器打开 YouTube/Google 依然提示「无法访问此网站」？

排查要点：
1. 系统代理没有开启：检查 Clash Verge 的「系统代理 (System Proxy)」或 v2rayN 托盘菜单的代理开关是否亮起；
2. 浏览器多余代理插件冲突：若浏览器安装了 SwitchyOmega 等插件，必须将其模式改为「系统代理」，否则浏览器不会走客户端流量。

Q3：打开代理后，国内软件（微信收发图、淘宝、B站刷视频）变得极慢甚至打不开？

排查要点：
您的路由模式被误设置成了 「全局 (Global)」，导致所有国内流量都绕道海外节点。解决办法：在客户端切换回 「规则 (Rule)」 或小火箭的 「配置 (Config)」 模式。在此模式下，系统会根据内置的大陆 IP 白名单自动分流，国内流量完全直连、零延迟、不消耗代理流量。

Q4：Clash 开启「TUN 模式」提示失败或报错？

排查要点：
TUN 模式需要底层安装虚拟网卡，请先彻底关闭客户端，以「以管理员身份运行」重新启动 Clash Verge Rev，再进入设置安装 TUN Service 服务。
